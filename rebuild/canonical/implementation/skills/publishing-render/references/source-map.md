# Production requirements

Use this map with the [production and artifact contract](output-contract.md).

| Requirement | Operational application |
| --- | --- |
| [Journey](../../../../docs/architecture/journey.md), [communication](../../../../docs/architecture/communication.md) | Produce the ordinary requested form from exact permitted content, with a readable handoff, design/value/encoding fidelity and actual per-form creation/export evidence. |
| [Objects](../../../../docs/architecture/business-objects.md), [knowledge](../../../../docs/architecture/knowledge.md), [decisions](../../../../docs/architecture/decisions.md) | Preserve source identity, evidence strength, uncertainty, human originals, information-use boundaries and separate review/release/acceptance decisions. |
| [Bindings](../../../workspace-bindings/contract.md), [catalog](../../../workspace-bindings/skill-contracts.json), [entity lineage](../../../contracts/entity-lineage.md) | Resolve source/settings/artifact homes only for needed operations, with current access and use authority. Preserve stable identities, old artifacts and partial correction coverage. |
| [Consult-deliverable](../../consult-deliverable/SKILL.md), [contract](../../consult-deliverable/references/output-contract.md) | In `delivery-content`, consume the exact Deliverable, Result/Baseline, criterion coverage and publishing handoff. Preparation or rendering does not complete missing promise criteria. |
| [Design-language](../../design-language/SKILL.md), [narrative-shape](../../narrative-shape/SKILL.md), [evidence-visualize](../../evidence-visualize/SKILL.md) | Always ask and wait for the production request's narrative choice. Yes uses narrative-shape and its consultant-chosen message/arc or explicit independent delegation before rendering; pending direction blocks production. No preserves supplied narrative. Compatible supplied design/graphics can replace their own preparation methods. Retain effective design, values/derivation, qualifications and client form. |
| [Publishing-inspect](../../publishing-inspect/SKILL.md) | Hand off the exact artifact and dependency receipt for its own inspection. Author production checks cannot substitute for independent inspection or human review. |

`supplied-content` accepts useful permitted content without a delivery engagement.
`delivery-content` additionally requires the exact compatible delivery handoff and
its source/interface evidence. A synthetic input remains explicitly synthetic.
For every form, observe the available authorized production route and preserve
failed/blocked/not-run dispositions. No documented or historical capability proves
current operation, and private rendering grants no publication or adoption authority.

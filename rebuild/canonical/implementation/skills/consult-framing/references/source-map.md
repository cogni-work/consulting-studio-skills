| Requirement | Apply it in the brief |

Missing required tailoring blocks that lane while permitted common framing continues. Keep supplied responsibilities, organizational levels, populations, units and periods distinct. |
| [Planning handoff](../../consult-planning/references/output-contract.md) | Carry baseline commitments, criteria, input needs, owners/dates or unknowns, and consequences without assigning new work or invoking analysis. |
| [Correction](../../../contracts/entity-lineage.md) | Changed bytes at the same label invalidate affected checks. Preserve human originals, issued promises and authority history; disclose unread dependent homes. |

Choose sale-handover, existing-framing or internal-work from the actual evidence.
Direct awards need no invented proposal; internal/pro-bono work needs no buyer or
order. An observable workshop result can be an acceptance criterion without a file.
An assessment date does not establish a start date or authority interval.

Read only the references needed for the selected task. Apply their current adopted
requirements within the actual audience, purpose and available authorized operations.
A method dependency names compatible information; it does not require a prior skill
invocation. Retain exact source versions and content identities when consuming outputs.

# Resume saved work

Read the [shared resume contract](references/resume-contract.md). Apply it to the
person's specifically identified saved work, through the current host's actual
supported read tools. This open auxiliary entry is separate from Setup, Workspace
Librarian and the 27 business methods. It requires no Studio App, D1 database,
Card, MCP server, Git access or network service. A supplied accessible local or
host-native document can be sufficient; no new project binding is inferred.

Resolve the exact original and requested revision before describing its state.
Read its relevant original evidence when the requested orientation depends on it;
report missing or partial reads. A familiar title, search snippet, remembered chat
or saved reference alone establishes no content, current status or authority.
For an ambiguous identity, ask one focused choice. For missing access, preserve the
known reference and name the gap without a replacement or wider search.

Use existing known entity-home and original references, scope and permissions.
When location work is actually needed, use the existing Workspace Librarian and
its common binding/storage rules through a supported workflow; do not require a
Librarian invocation for a concrete readable document. Setup and org-specialize
own configuration proposals and human adoption. A read of this work establishes
neither global Settings status nor discovery or later-session application.

An explicit Studio project/card/result binding selects the App adapter when it is
actually available. The adapter uses the same shared resume contract and the
existing exact Studio read and deterministic GUI status. If that bound read fails,
report its precise gap; never replace it with a neutral reconstruction. Missing
App support blocks that bound route, not independently requested neutral work.

Return short `present`, `open` and `next` orientation in the person's language,
with one useful next step and its reason. For a status-only request, stop there.
Propose any continuation through the appropriate available business method; this
read-only helper does not automatically continue, save, adopt, provision, publish
or repeat an uncertain effect. The next step is a proposal, not authorization.

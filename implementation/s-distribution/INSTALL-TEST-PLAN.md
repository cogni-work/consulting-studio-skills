## Failure and stopping rules

An unavailable route/tool is BLOCKED or NOT_RUN with actual surface, action and
settling condition. A stale ref or wrong artifact stops before import/adoption.
An access/policy denial stops that affected operation; no alternative route is used
to bypass it. On timeout or uncertain import/sync/write, inspect the actual current
state and record applied/unapplied/mixed/unknown before considering a retry. Unknown
outcome blocks a repeat. Keep the last approved package and evidence; continue only
independent permitted work. The owner-authorized public repository/release
publication has its own timed plan and readback in OWNER-DECISIONS.md. Marketplace publication, installation and any
new credentials/permissions still require separate applicable owner authority.

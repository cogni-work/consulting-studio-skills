# Known limits

S1.2.2 is **owner-tested and accepted for the documented scope**. The successful
owner test covers Setup and one bounded problem-framing workflow with Astra,
including fresh reads of settings and required references. Additional
owner-reported work demonstrated reuse of an existing project, an authorized
Pages save/readback and reuse of existing framing for stakeholder content; the
exact model and package version of those later runs were not separately confirmed.
See [the audit record](AUDIT.md#testing-status-and-limitations).

- The full 27-method / 35-mode catalog, all models, colleague/team access, broad
  client or surface compatibility, controlled update and recovery have not been
  established by these tests. The successful bounded workflows remain valid.
- The plugin supplies consulting instructions and resources. It ships no Studio
  GUI, MCP server, Worker app or method execution engine, and requires no
  Workspace Agent. External research, storage, rendering and inspection need
  actual supported tools, access and authority in the selected environment.
- A plugin download grants no data access. Installation eligibility, plugin
  availability and each connected app's permissions remain host/workspace specific.
  No general ChatGPT/Codex/Desktop/mobile compatibility or automatic update claim
  follows from the documented Astra test.
- Required child-resource reading is essential. Root-only reads, recited hashes,
  names or truncated tool output establish no complete required-section coverage.
  An unavailable required section limits the dependent workflow.
- The public repository has no marketplace catalog. Use the documented plugin ZIP
  upload route when available; this GitHub release is not Marketplace submission.
- Only the explicitly labelled fictional Setup example is included. Historical
  rendered/private fixtures and evaluation adapters are excluded. A retained
  evaluation-only locator is frozen contract vocabulary, not a required file read.
- Rebuild sources include a finite snapshot and tools, not private history or full
  authoring catalogs. Provenance commit IDs are evidence, not promised public URLs.
- Customer adaptations/settings, human notes and issued work remain separately
  owned. Recovery of package bytes cannot undo external effects.
- S1.2.2 preserves the exact owner-tested installer bytes. Later report-contract and
  work-location changes are outside this release. Historical build-time candidate
  statements remain in package metadata; current publication and acceptance are
  recorded separately in the release and repository documentation.

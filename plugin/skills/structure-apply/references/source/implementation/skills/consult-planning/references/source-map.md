# Operational requirements for delivery planning

| Requirement | Apply it in the plan |
| --- | --- |
| [Framing contract](../../consult-framing/references/output-contract.md) | Carry complete exact agreed framing and authority; compatible supplied framing is sufficient. No sale, formal tree or prior invocation is mandatory. |
| [Delivery journey](../../../runtime/requirements.md#business-lifecycle) | Group useful work, client inputs, milestones and risks/issues/assumptions/dependencies with owners, next actions and result criteria. |
| [Delivery objects](../../../runtime/requirements.md#business-records) | Link work and milestones to baseline commitments. Keep expected outcomes separate from delivered output and acceptance. |
| [Authority](../../../runtime/requirements.md#human-decisions) | Assess current permitted work against actual order/internal authority, scope, period, supplements, responsible usage and stop conditions. Preparation does not extend authority. |
| [Knowledge and methods](../../../runtime/requirements.md#evidence-and-knowledge) | Preserve use basis, source coverage, local exceptions, human notes/dissent and exact applicable method/settings. A framing reference alone does not supply an analysis method. |
| [Communication](../../../runtime/requirements.md#communication) | Lead with practical next work and blockers, edit for an unfamiliar reader, preserve qualifications and label simulations as self-checks. |
| [Corrections and lineage](../../../runtime/entity-lineage.md) | Preserve issued work and exact input identities; report affected work/checks and unread dependencies on resumption. |

A missing day-3 input assessed on day 4 can threaten the committed day-10 report;
show the settling owner/action and consequence without inventing a revised date
or critical-path duration. Reconcile received lists for receipt and coverage rather
than requesting them again. Preserve the original narrow assignment and due date
on correction; completion/current applicability remains unknown until established.
New coverage review and chasing remain proposed and unassigned without evidence.

Read only the references needed for the selected task. Apply their current adopted
requirements within the actual audience, purpose and available authorized operations.
A method dependency names compatible information; it does not require a prior skill
invocation. Retain exact source versions and content identities when consuming outputs.

# Operational requirements for closure and outcomes

| Requirement | Apply it in the note |
| --- | --- |
| [Closure journey](../../../runtime/requirements.md#business-lifecycle) | Preserve exact acceptance/reservations, commercial readiness, conclusion/cancellation, remaining obligations and settled exit. |
| [Decisions](../../../runtime/requirements.md#human-decisions) | Bind each decision to its exact subject and effective engagement-specific authority. Silence is not acceptance; cancellation stops new delivery before cleanup. |
| [Business objects](../../../runtime/requirements.md#business-records) | Keep stable Reservation, Closure and Outcome identities and historical/current versions distinct. |
| [Reuse and exit](../../../runtime/storage-lifecycle.md#reuse-revocation-and-exit) | Inspect every outgoing surface against every owner's current exact use grant. An anonymous-lesson grant is no right to export a dossier, benchmark or reference call. |

| [Status](../../consult-status/references/output-contract.md) and [change](../../consult-change/references/output-contract.md) | Reconcile different baselines and preserve exact adopted changes, pending promises, original order, current work limits and attributed observations. |
| [Correction](../../../runtime/entity-lineage.md) | Preserve issued work, decisions, human originals and late objections; report stale support and unread dependencies without a blind retry. |

Deemed acceptance requires the exact pre-agreed procedure, delivery/subject receipt,
elapsed period and affirmative no-response coverage. Attribute its result to that
procedure, never a fabricated client sign-off. A reservation resolved on a new
version does not rewrite historical acceptance. Invoice readiness, invoiced, paid
and achieved outcome each require their own evidence.

Assess later outcomes only when requested and supported by named data-owner
observations, objectives and comparable measures. Keep population, period, unit,
denominator, missingness and attribution limits visible; unsupported comparisons
remain not assessable. No measure is mandatory where none was named.

Read only the references needed for the selected task. Apply their current adopted
requirements within the actual audience, purpose and available authorized operations.
A method dependency names compatible information; it does not require a prior skill
invocation. Retain exact source versions and content identities when consuming outputs.

# Operational requirements for defensible results

| Requirement | Apply it in the answer |
| --- | --- |
| [Evidence-research contract](../../evidence-research/references/output-contract.md) | Consume exact permitted evidence, source quality, read coverage, contrary passages and gaps; direct supplied evidence needs no engagement or prior invocation. |
| [Chosen-method contract](../../structure-apply/references/output-contract.md) | Only chosen-method mode requires attributable choice/rejection, readable applicable method rights and actual application with exact branch/rule/result lineage. Choice alone is not application. |
| [Results and relationships](../../../runtime/requirements.md#business-records) | A Result can remain inline, acquire a stable identity and be promoted or corrected without a fabricated Deliverable or Artifact. |
| [Defensible evidence](../../../runtime/requirements.md#evidence-and-knowledge) | Preserve documentary/stated/assumed/inferred basis, exact passages, omissions and measurement definitions. Absence is open; narrow contrary evidence does not prove a broader causal conclusion. |
| [Decisions](../../../runtime/requirements.md#human-decisions) | Recommendations remain proposals; they change no assignment, standard, baseline, release or acceptance. |
| [Communication](../../../runtime/requirements.md#communication) | Answer the question at its actual strength, with rationale, limits, alternatives and useful proposed actions. |
| [Deliverable handoff](../../consult-deliverable/references/output-contract.md) | Carry supported/refuted/open findings, exact dependencies and unresolved requested-form gaps. An outline is not an inspected deck. |
| [Correction](../../../runtime/entity-lineage.md) | Same-label evidence, method or application changes invalidate affected findings/summary/recommendations/checks; retain human originals and issued uses. |

Keep supplied P/RQ/CI identifiers, empty unsupported cells, organizational levels,
exceptions, definitions, units, populations and periods. Do not
pool incompatible figures, rank completeness without a basis, infer a legal mandate,
or claim causality, adoption, achieved benefits or savings without support.

Read only the references needed for the selected task. Apply their current adopted
requirements within the actual audience, purpose and available authorized operations.
A method dependency names compatible information; it does not require a prior skill
invocation. Retain exact source versions and content identities when consuming outputs.

Inspect actual pixels for each claimed page/slide or disclose exact limited
coverage. Source text, a file hash, a rendering command and historical author checks
cannot substitute. Editable notes/chart/workbook and PDF exports are distinct
surfaces: hidden notes do not supply evidence absent from the export. Recompute
applicable values and compare their actual labels/encoding and visible limits.

A corrected artifact receives fresh findings and retest evidence with overall
`FINDINGS_FOR_REVIEW`; it inherits no acceptance. Changed source, filter,
aggregation, encoding or narrative bytes invalidate affected checks even at the
same locator/version label. Keep old artifacts, findings and human decisions fixed.

Read only the references needed for the selected task. Apply their current adopted
requirements within the actual audience, purpose and available authorized operations.
A method dependency names compatible information; it does not require a prior skill
invocation. Retain exact source versions and content identities when consuming outputs.

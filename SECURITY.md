# Security reporting and updates

S1.2.2 is owner-tested and accepted for the documented scope described in
[AUDIT.md](AUDIT.md#testing-status-and-limitations). This is separate from security
certification. No monitoring, emergency coverage, response deadline or remote
customer access is promised.

The owner-approved private reporting contact is **stephan@cogni-work.ai**. Send
suspected vulnerabilities privately rather than disclosing sensitive details in
public issues. Do not send a report as part of testing this repository.

Preserve the exact affected version/hash and a minimal sanitized fictional
reproduction. Exclude credentials, private records and live bindings. The
maintainer assesses severity, affected versions and a correction, advisory or
mitigation; no fixed acknowledgement, response or resolution time is committed.
Customers preserve the prior approved package/settings, inspect the advisory,
test the exact proposed update and deliberately adopt it. If effects are uncertain,
inspect before retry. Recovery restores supported package/configuration state;
already issued work and external effects need their own reconciliation.
